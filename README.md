# CapCut Automation + Stock Fetcher

Набор утилит с графическим интерфейсом (`gui.py`) для автоматизации подготовки проектов CapCut и загрузки стоковых видео.

## Модули

- **`gui.py`** — оконный интерфейс (вкладки *Обработка проекта* и *Скачать видео*).
- **`clear_vids.py`** — масштабирование клипов и скрытие вотермарок Gemini/Veo с помощью OpenCV.
- **`make_transitions.py`** — циклическая расстановка переходов по паттерну между клипами основной дорожки.
- **`setup_audio.py`** — intro/ambient по сценарию (конец интро выравнивается по кадру «начнём с…»), плавный переход intro → ambient, нормализация озвучки, Fade Out финального клипа и видео с призывом подписаться верхним слоем.
- **`stock_fetcher.py`** — скачивание видео с YouTube (через `yt-dlp`, с вырезкой фрагмента по таймкоду), Pexels и Pixabay, а также пакетная выкачка по файлу тегов.
- **`capcut_common.py`** — общие функции работы с черновиками CapCut (поиск `draft_content.json` / `draft_info.json`, проверка запущенного CapCut, атомарная запись, ротация `.backups` и синхронизация с `Timelines/<uuid>/draft_content.json`).

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python gui.py
```

Для CLI-использования любого модуля можно передать `--help`:

```bash
python clear_vids.py --help
python make_transitions.py --help
python setup_audio.py --help
python stock_fetcher.py --help
```

## Сборка `.exe` (PyInstaller)

Конфигурация сборки с иконкой зафиксирована в `CapCutAutomation.spec`:

```bash
pyinstaller CapCutAutomation.spec
```

Готовый файл появится в `dist/CapCutAutomation.exe`. Настройки GUI (`gui_settings.json`) и паттерн переходов (`transitions_config.json`) сохраняются в `%APPDATA%\CapCutAutomation`.

## Аудио: intro → ambient по сценарию

`setup_audio.py` ставит intro так, чтобы его конец совпал с кадром, где в сценарии начинается
основная часть («начнём с…», «начинаем…» и т. п.), а ambient — сразу за ним.

- **Файл промптов кадров** (`.txt`) — блоки `[PROMPT #N]` с описанием кадра, под ними в `[...]`
  фрагмент сценария. Номер промпта связывается с клипом `<N>.mp4` на основной дорожке проекта.
  Если клип заменён стоковым видео без номера, позиция вычисляется по соседним нумерованным клипам.
- **Поиск фразы** — регулярное выражение (по умолчанию `\bнач(?:нём|нем|инаем|алось)\b`). Если фраза
  не найдена, скрипт покажет похожие кадры с их временем — нужный кадр можно задать вручную.
- **Хвост intro** — последние 6 секунд файла не используются (там плохой звук).
- **Подгонка длины** — если интро (без хвоста) длиннее кадра, лишнее отрезается с начала;
  если короче — интро **замедляется** (speed < 1), чтобы конец попал ровно в кадр
  (source_duration / speed = длина до кадра). Максимальное замедление — 4x (0.25);
  если его не хватает, выводится предупреждение и звук заканчивается раньше кадра.
- **Переход** — у intro Fade Out 4.5 с, у ambient Fade In 3 с; общая громкость -7 дБ.
  В начале intro Fade In **отключён** (0 с): звук появляется сразу, без «нарастания».
  Ambient заканчивается Fade Out 4 с вместе с видео.
- **Видео с подпиской** — если указан файл, он кладётся оверлеем на дорожку выше основной
  в трёх местах: два — по кадрам сценария, где встречается «подпишись» в любой форме
  (`подпи[сш]…`: подпишись, подпишитесь, подписка и т. п.); третье — ровно посередине ролика.
  Если в пределах ±3 минут от середины есть кадр с призывом к комментариям («коммент…»),
  оверлей ставится на нём вместо середины. Размер, положение и удаление зелёного фона
  повторяют эталонный проект CapCut.

Пример:

```bash
python setup_audio.py "D:\\Для работы\\CapCut Drafts\\<проект>" \
    --intro "D:\\...\\disc intro epic 1.MP3" \
    --ambient "D:\\...\\ambiant 1 disc.MP3" \
    --prompts "D:\\Для работы\\YouTube\\Видео 14\\Промты 84.txt"
```

Полезные флаги: `--prompts <файл>`, `--anchor-prompt <№ кадра>` (вместо поиска по фразе),
`--anchor-markers <regex>`, `--intro-tail 6`, `--intro-fade-in 0`, `--intro-fade-out 4.5`,
`--ambient-fade-in 3`, `--subscribe <видео.mp4>`, `--subscribe-middle-window 180`.

В GUI остались только поля, которые реально меняются: «Промпты кадров», «Видео с подпиской»,
«Маркер конца интро», «Кадр №», «Озвучка». Остальное зашито в коде: громкость −7 дБ, fade 4 с,
хвост интро 6 с, Fade In интро 0 с, Fade Out интро 4.5 с, Fade In ambient 3 с, нормализация
озвучки −23 LUFS и Fade Out последнего клипа включены всегда.

## Настройка переходов

По умолчанию паттерн переходов задан в `make_transitions.py`. Для переопределения без правки кода можно создать файл `transitions_config.json` в `%APPDATA%\CapCutAutomation` (или рядом со скриптом):

```json
{
  "durations_sec": {
    "7159450506648097281": 1.0,
    "7140916992118100482": 1.0,
    "7184693655641264641": 0.9,
    "7140916996262072833": 0.8
  },
  "pattern": [
    "7159450506648097281",
    "7140916992118100482",
    "7184693655641264641",
    "7140916996262072833"
  ]
}
```

## Краткий гайд по работе с программой

Порядок обработки одного ролика: **масштаб/вотермарки → переходы → аудио**.
В GUI это три блока на вкладке «Обработка проекта»; кнопка **«▶▶ Запустить всё подряд»**
проходит их по очереди, кнопка **«▶ Только аудио»** запускает только звук.
Перед запуском **закройте CapCut** — файлы проекта правятся напрямую.
Перед каждой записью создаётся бэкап в `.backups`, вернуть предыдущую версию можно кнопкой
**«↩ Откатить бэкап»**. Галочка «Пробный прогон» в каждом блоке — пройти без записи.

Если в проекте есть папка `Timelines` (новые версии CapCut), изменённый `draft_content.json`
автоматически записывается и в `Timelines/<uuid>/draft_content.json`. Без этого CapCut при
открытии мог бы загрузить старый таймлайн и перезаписать изменения. Если папки `Timelines`
нет — сохраняется только один файл, как раньше.

### 1. Убирание вотермарок

Блок **«1. Масштаб + вотермарка»** (`clear_vids.py`) увеличивает клипы и сдвигает кадр так,
чтобы логотип Gemini/Veo ушёл за край, а итоговое разрешение осталось прежним.

1. Выберите проект в списке сверху (или «Обзор…» → папка проекта).
2. Проверьте «Масштаб» — по умолчанию `1.15`.
3. При необходимости раскройте «Дополнительно»: пороги поиска логотипа, номер дорожки,
   размер кадра, свои флаги.
4. «Чистым клипам сбрасывать сдвиг X в 0» — выравнивание клипов, где вотермарки не было;
   «Сохранять картинки проверки» — сложить кадры и найденные рамки в `debug/`.
5. **«▶ Запустить»**.

CLI:

```bash
python clear_vids.py "D:\...\проект" --scale 1.15
python clear_vids.py "D:\...\проект" --threshold 0.46 --dry-run --debug-dir debug
```

Если логотип не найден — понизьте порог (`--threshold`), для одиночного кадра есть
`--threshold-single`, а координаты можно задать вручную: `--marks 0.906,0.833,0.037`.

### 2. Постановка переходов

Блок **«2. Переходы»** (`make_transitions.py`) ставит переходы между клипами основной
дорожки по кругу, с длительностью для каждого типа.

1. Нажмите **«⚙ Настроить паттерн переходов…»**: отметьте переходы, задайте длительность
   и порядок. Настройка хранится в `transitions_config.json`.
2. Отметьте нужное: «Пропускать стыки, где начинается оверлей», «Не ставить после 1-го
   и перед последним клипом».
3. «Параметры частоты»: каждый N-й стык, вероятность, минимальная длина клипа, seed.
4. **«▶ Запустить»**.

CLI:

```bash
python make_transitions.py "D:\...\проект"
python make_transitions.py "D:\...\проект" --every 2 --chance 60 --seed 42
python make_transitions.py "D:\...\проект" --skip-overlays --skip-edges --dry-run
```

### 3. Аудио

Блок **«3. Аудио»** (`setup_audio.py`) ставит интро и фоновую музыку, включает нормализацию
озвучки и Fade Out последнего клипа. Конец интро выравнивается по кадру из сценария.

1. **Intro** — файл интро, **Ambient** — фоновая музыка (кнопки «Обзор…»).
2. **Промпты кадров** — `.txt` с блоками `[PROMPT #N]` и сценарием в `[...]` под каждым.
3. **Видео с подпиской** — `.mp4` с кнопкой подписки (необязательно). Оставьте поле пустым,
   чтобы не добавлять оверлей.
4. При необходимости: **Маркер конца интро** — фраза, по которой ищется кадр
   (по умолчанию «начнём с / начинаем»); **Кадр №** — номер кадра вручную,
   если фразу не нашли (скрипт подскажет похожие кадры с их временем).
5. **Озвучка** — часть имени дорожки с голосом (по умолчанию `voice`).
6. **«▶ Только аудио»** внизу (или «Запустить всё подряд»).

Что ставится автоматически, менять не нужно:

- громкость интро и ambient −7 дБ;
- в начале интро нет Fade In — звук не «нарастает»;
- последние 6 секунд интро не используются (там плохой звук);
- конец интро — ровно на кадре: длинное интро подрезается с начала, короткое замедляется
  (speed < 1), чтобы попасть в кадр;
- Fade Out интро 4.5 с → Fade In ambient 3 с, ambient заканчивается Fade Out 4 с;
- видео с подпиской ставится на дорожку выше основной: два раза по слову «подпишись»
  и один раз посередине (или на кадре с призывом к комментариям рядом с серединой);
- нормализация озвучки −23 LUFS и Fade Out последнего видеоклипа.

CLI:

```bash
python setup_audio.py "D:\...\проект" \
    --intro "D:\...\disc intro epic 1.MP3" \
    --ambient "D:\...\ambiant 1 disc.MP3" \
    --prompts "D:\...\Промты 84.txt" \
    --subscribe "D:\...\YouTube_Subscribe_button.mp4"
python setup_audio.py "D:\...\проект" --intro ... --ambient ... --anchor-prompt 24 --dry-run
```
